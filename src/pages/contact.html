02기사 수정·삭제 요청 절차

원문 매체나 권리자께서 요청하는 경우, 아래 내용을 적어 보내 주시면 확인 후 해당 카드를 수정하거나 삭제합니다. 트렌드픽은 제목·링크·썸네일만 인용하지만, 요청이 타당하면 지체 없이 반영합니다.

  1. 기사 제목과 트렌드픽 화면의 URL(또는 원문 URL)
  2. 요청 사유 — 저작권, 명예훼손, 사실관계 오류, 삭제 요청 등
  3. 요청 내용 — 제목 수정, 링크 해제, 카드 삭제 중 무엇을 원하는지
  4. 권리자 확인 자료 — 매체명, 담당자, 필요 시 권리 증빙

접수 후 영업일 기준 2~3일 안에 확인 결과를 회신합니다. 긴급한 사안(명백한 권리 침해, 심각한 오류)은 제목에 [긴급]을 붙여 주시면 우선 처리합니다.

03오류·링크 제보

다음과 같은 문제를 알려 주시면 큰 도움이 됩니다. GitHub Issues에 남겨 주시면 처리 과정을 함께 볼 수 있습니다.

  • 카드를 눌러도 원문이 열리지 않거나 다른 페이지로 연결되는 경우
  • 썸네일이 깨지거나 기사와 무관한 이미지가 붙은 경우
  • 브리프의 숫자·고유명사가 원문과 다른 경우
  • 같은 기사가 여러 번 노출되거나 분야가 잘못 분류된 경우

04제휴·광고 문의

제휴, 광고, 콘텐츠 협업 제안은 이메일 제목에 [제휴]를 붙여 보내 주세요. 다만 기사 순서나 평가를 광고비 조건으로 바꾸는 제안은 받지 않습니다. 광고 지면과 제휴 표시 기준은 편집·큐레이션 원칙에 정리해 두었습니다.

쿠팡 파트너스 링크는 특가·핫딜 영역에만 사용하며, 해당 영역에 수수료 고지를 표시합니다. 자세한 내용은 개인정보처리방침을 참고해 주세요.
