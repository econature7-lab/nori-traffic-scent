# 트렌드픽 TrendPick v3 · 필수 패키지

# GitHub Actions 기본 러너에는 모두 미리 설치되어 있으나,
# 로컬에서 동일 환경을 만들고 싶을 때 사용하세요.

# 선택: sources.yaml 을 코드에서 직접 읽어 소스 목록을 덮어쓸 때
# PyYAML>=6.0
#
# 선택: requests 로 수집기를 확장할 때 (현재 코드는 urllib 사용)
# requests>=2.32
#
# 선택: RSS 파싱을 feedparser 로 바꿀 때 (현재 코드는 xml.etree 사용)
# feedparser>=6.0
#
# 선택: 로컬 미리보기용
# playwright>=1.45

# 위 항목을 모두 주석 처리해 둔 이유:
#   비어 있는 requirements.txt 로도 `pip install -r requirements.txt` 가
